Python Projects

This folder contains two simple Python projects developed for academic purposes to practice and demonstrate basic Python programming concepts: a Simple Function and Simple File Writing.

Projects

Simple Function

The Simple Function program asks the user to enter their name. It uses a function named `greet()` that takes the person's name as a parameter and displays a greeting message.

Features:

* Takes the person's name as input.
* Creates a function named `greet()`.
* Takes the name as a function parameter.
* Calls the `greet()` function.
* Displays a greeting message using the entered name.

Example:

```text
Enter name: Rahim
Hello Rahim
```

Simple File Writing

The Simple File Writing program asks the user to enter their name and saves the entered name into a file named `name.txt`.

Features:

* Takes the user's name as input.
* Opens or creates a file named `name.txt`.
* Writes the entered name into the file.
* Closes the file after writing.
* Displays a success message after saving the name.

Example:

```text
Enter your name: Karim
Name saved successfully.
```

Setup and Run Instructions

Prerequisites

Make sure Python is installed on your computer.

Run Simple Function

Open a terminal and navigate to the Simple Function folder, then run:

```text
python greet.py
```

Enter the person's name when prompted.

Run Simple File Writing

Navigate to the Simple File Writing folder and run:

```text
python file_writing.py
```

Enter your name when prompted. The program will save the entered name in `name.txt`.
